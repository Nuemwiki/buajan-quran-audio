# Abdullah Albuajan - Ayet Ayet Kuran-ı Kerim Tilaveti

Bu depo, Mescid-i Nebevi İmamı **Şeyh Abdullah el-Buaycan**'ın (Abdullah Albuajan) Kuran-ı Kerim tilavetinin MP3Quran resmi Timing API verileri doğrultusunda FFmpeg ile ayet ayet dilimlenmiş 128 kbps MP3 ses dosyalarını barındırır.

## Özellikler & Akustik Düzenlemeler:
- **Eûzü Ayıklaması:** Fatiha hariç her surenin başındaki Eûzü kısmı (`0 - 5.0s`) ayıklanmış, 1. ayetler tertemiz Besmele ile başlatılmıştır (Besmelesiz Tevbe suresi hariç).
- **İsimlendirme Formatı:** `{sure_3_hane}{ayet_3_hane}.mp3` (Örn: Fatiha 1. ayet: `001001.mp3`, Cin 15. ayet: `072015.mp3`).
- **Hafız AI & jsDelivr CDN:**
  `https://cdn.jsdelivr.net/gh/Nuemwiki/buajan-quran-audio@main/audio/{sure_no}{ayet_no}.mp3`
